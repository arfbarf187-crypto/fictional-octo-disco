# Walter Ego NFT Website Starter

This is a static multi-page website starter built for use in Microsoft Visual Studio / Visual Studio Code.

## Included Pages
- index.html
- crew.html
- production.html
- universe.html
- gallery.html
- contact.html

## Folders
- assets/css/styles.css
- assets/js/app.js
- assets/img/purple-diamond.svg

## Important image note
The homepage hero is already styled to support a custom background image.
To use your own crew image:
1. Add your image file into `assets/img/`
2. Name it `hero-placeholder.jpg`
3. Refresh the browser

## How to run locally
1. Open the folder in Visual Studio or Visual Studio Code
2. Open `index.html`
3. Use a Live Server extension or your preferred local preview

## Domain deployment
Upload the full folder contents to the hosting account connected to `www.walteregonft.com`.
If your host expects a `public_html` folder, place the site files there.
